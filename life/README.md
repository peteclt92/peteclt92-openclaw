# life/ — Entity Notes (Light Memory System)

This folder is the **clean, human-readable entity layer** for Clawdbot.

Goals:
- Keep context **current** without turning `MEMORY.md` into a junk drawer.
- Store information by **entity** (people, projects, companies).
- Keep it safe: **conservative**, minimal, and auditable.

## Structure
- `people/` — one file per person
- `projects/` — one file per project
- `companies/` — one file per company

## Rules
- Prefer **plain Markdown**, no complex schemas.
- Split facts into:
  - **Confirmed** (high confidence)
  - **Proposed (unverified)** (needs confirmation)
- Avoid sensitive personal data unless explicitly requested.
